# MusorClean

MusorClean — утилита для системного администрирования, быстрой очистки мусора и обслуживания Windows. Программа написана на C# с использованием .NET.

# Основные возможности

* Глубокая очистка: удаление временных файлов, кэша и системного мусора.
* Быстрый доступ к командам: запуск sfc /scannow, gpupdate /force, DISM для восстановления образа системы и управление питанием.
* Простой интерфейс без лишних элементов.

# Как запустить готовый билд

Если не хочется собирать проект из исходников:

1. Зайдите в папку Build в этом репозитории.
2. Скачайте файлы сборки.
3. Запустите MusorClean.exe.

# Сборка из исходников

1. Клонируйте репозиторий:
git clone [https://github.com/cozmo38t-dev/MusorClean.git](https://github.com/cozmo38t-dev/MusorClean.git)
2. Откройте проект в Visual Studio (требуется .NET SDK для Windows Forms).
3. Соберите и запустите проект.
